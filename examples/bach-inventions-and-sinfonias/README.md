# Bach Inventions and Sinfonias, BWV 772–801

This collection contains Johann Sebastian Bach's complete set of two-part inventions and three-part sinfonias as independently openable ScoreMaker files:

- `inventions/`: 15 two-part inventions, BWV 772–786
- `sinfonias/`: 15 three-part sinfonias, BWV 787–801

The scores use public-domain Bach compositions and MIDI transcriptions from the Mutopia Project. The Mutopia editions are based on the Bach-Gesellschaft and are either public domain or distributed under Creative Commons Attribution-ShareAlike 3.0. Individual source details are preserved in each score's annotation metadata.

Source collection: https://www.mutopiaproject.org/cgibin/make-table.cgi?collection=bachis&preview=1
