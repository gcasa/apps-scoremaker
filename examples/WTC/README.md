# The Well-Tempered Clavier, BWV 846–893

This directory contains all 96 movements of Johann Sebastian Bach's *Well-Tempered Clavier* as independently openable ScoreMaker `.score` files:

- `book-1/`: 24 preludes and 24 fugues, BWV 846–869
- `book-2/`: 24 preludes and 24 fugues, BWV 870–893

The filenames begin with each pair's number and BWV catalog number. Book II uses the autograph versions of Preludes 1 and 24.
